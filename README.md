# 📝 Registration Form with JavaScript Validation

## 📌 Overview
A responsive registration form that validates user inputs in real-time using vanilla JavaScript. The goal is to prevent invalid data submission and provide immediate feedback.

## 🎯 Objectives
- To create a user-friendly registration form
- To implement client-side validation
- To handle form states (disable/enable submit button)

## ✅ Validation Logic
| Field    | Validation Rule | Error Message |
| --- | --- | --- |
| Name     | Not Empty | Name is required |
| Email    | Valid format check | Please enter a valid email |
| Password | Min 6 chars | Password must be at least 6 characters |

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3
- **Logic:** JavaScript (ES6)
